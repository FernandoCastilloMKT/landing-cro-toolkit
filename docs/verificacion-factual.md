# Verificación factual

Crea un inventario de afirmaciones antes de publicar. Para cada una registra texto exacto, fuente primaria, fecha de comprobación, alcance, condiciones y responsable de aprobarla.

## Fuentes preferidas

1. Documentación contractual o técnica propia autorizada.
2. Registros y organismos oficiales.
3. Documentación original del fabricante o proveedor.
4. Fuentes secundarias fiables, solo como apoyo.

Una web de un competidor no demuestra una afirmación propia. Una captura sin fecha tampoco. Los testimonios requieren permiso y deben conservar su sentido. Si una afirmación cambia con el tiempo, asigna fecha de caducidad y responsable de revisión.

Cuando no haya evidencia suficiente, elimina el dato, reformúlalo como objetivo no factual o sustitúyelo por una explicación comprobable del proceso.
