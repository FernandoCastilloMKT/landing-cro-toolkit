# Método CRO para landings

## 1. Evidencia antes que diseño

Define audiencia, intención de búsqueda, oferta, objeciones, diferenciadores y acción principal. Crea una tabla de afirmaciones con fuente, fecha y responsable. Si no existe evidencia, no publiques la afirmación.

## 2. Arquitectura del mensaje

1. Hero: qué se ofrece, para quién, beneficio verificable y CTA.
2. Prueba: mecanismo, casos autorizados o datos respaldados.
3. Solución: beneficios conectados con objeciones reales.
4. Proceso: siguientes pasos y expectativas.
5. Confianza: condiciones, garantías y credenciales verificadas.
6. FAQ: dudas que frenan la conversión.
7. Cierre: CTA coherente y alternativa de contacto.

## 3. Diseño

Prioriza lectura rápida, jerarquía clara, contraste, espacios consistentes, controles táctiles amplios y estados visibles. Evita carruseles automáticos, falsas urgencias, patrones engañosos y CTAs competidoras.

## 4. Experimento

Formula una hipótesis con audiencia, cambio, resultado esperado y métrica. Cambia una idea relevante cada vez; define duración y criterio de decisión antes de mirar resultados. Documenta también los resultados negativos.
