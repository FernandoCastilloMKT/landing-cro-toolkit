# Cómo contribuir

1. Abre un Issue para describir el problema o mejora.
2. Crea una rama desde `main`.
3. Haz cambios pequeños, documentados y sin datos reales de empresas o personas.
4. Ejecuta `python scripts/audit_public_repo.py .`.
5. Comprueba la landing en móvil y escritorio, teclado, formulario, enlaces y consola.
6. Abre un Pull Request explicando el objetivo, las pruebas y las capturas necesarias.

No incluyas datos de clientes, leads, analítica, cuentas publicitarias, credenciales, dominios privados, materiales sin licencia ni afirmaciones no respaldadas. Usa siempre marcas, datos y testimonios ficticios claramente señalados.
